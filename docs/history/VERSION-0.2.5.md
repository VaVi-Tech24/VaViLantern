# VaVi Lantern 0.2.5

Jonah's arms are shorter and proportioned to his torso, with a compact bent-elbow pose. The free-arm swing follows the sprite running cycle with reduced amplitude. The torch returns closer to his body.

Deck boards now run crosswise, appearing as repeated vertical seams (|||||), with small gaps, lengthwise grain on each board and two supporting logs underneath. Individual short sections collapse behind the runner.

Browser visual check, campaign tests, UI smoke checks and service tests passed. Progress and jump physics remain unchanged. APK output is a debug-signed testing build; the release bundle is unsigned.
