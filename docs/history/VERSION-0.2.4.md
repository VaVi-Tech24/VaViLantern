# VaVi Lantern 0.2.4

Jonah's free arm now uses smoothly rotating shoulder and elbow joints, replacing the rotating sprite cutout. The torch arm extends forward with clearance between the full flame and his face. The painted head, vest and running legs remain.

The bridge deck has three long horizontal board rows, continuous lengthwise grain and sparse staggered end joints. Paired supporting logs and collapse behavior remain.

Browser visuals and campaign, UI lifecycle and service checks passed. Android output is a debug-signed testing APK and unsigned release bundle. Progress and jump physics are unchanged.
