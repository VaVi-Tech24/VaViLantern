# Features and current scope

## Included in version 1.0.0

- Shared browser and Android game with a lightweight 2D Canvas renderer.
- Twenty-five unlockable levels, from 2000 m to 69000 m, with four difficulty bands.
- Walk/sprint tradeoff between flame recovery and distance from the advancing collapse.
- Single, double, triple and later four-to-six-jump crossings, with sparse gaps and recovery stretches.
- Six named travelers; Jonah default and Pranay last in the menu.
- Three flame-refill lantern posts per route; start/end gateways and level-start retries.
- Moving diagonal wooden planks, collapse animation, centered runners and water-fall/splash effects.
- Day/night alternation, dusk preview, layered mountains, clouds, birds, fish, fixed sun/moon and cosmetic fireballs.
- Responsive pointer/keyboard controls and same-device two-player bridges.
- Local progress, recent records, character and sound settings.
- Synthesized jump, sprint, slide, refill, finish and splash sounds, with mute and audio lifecycle handling.
- Supplied VaVi Tech logo and footer reading copyright VaVi Tech 2026.
- Optional server-authoritative two-player invitations and rolling seven-day run leaderboard.

## Available source, not a live production service

The optional Node server is runnable and tested locally. Public online hosting, domain connection and live leaderboard operations are not configured. Static hosting serves solo/same-device play only. HTTP polling has noticeable network-latency limitations; there is no prediction or WebSocket transport.

## Not implemented

Accounts, cross-device saves, ghost replay, ads, in-app purchases, paid skins, daily friend challenges, cash payouts, production anti-bot protection, verified unique-person rankings and a native 3D renderer. Generated shades/glows mean the artwork is not strictly limited to 16 indexed colors. The game makes no medical claim about serotonin or dopamine.

## Release interpretation

Version 1.0.0 identifies the requested code and binary release. The attached APK remains a development-signed test build, and the AAB is unsigned. Publishing a GitHub release does not satisfy Play Console signing, testing, privacy or store-review requirements.
